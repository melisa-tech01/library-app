# Library App

A simple library management system built with Python.

## Features

* User login with username and password
* Hidden password input using `getpass`
* Display available and borrowed books
* Borrow books
* Return books
* Password changing
* Logout
* Case-insensitive book search
* Input validation for invalid menu choices
* Detection of books that do not exist

## What I Practiced

* Lists and nested lists
* `for` loops
* `while` loops
* `if`, `elif`, and `else`
* User input with `input()`
* Boolean values
* `getpass` for hidden password input
* Searching through lists
* Updating data inside nested lists
* Program flow and login sessions

## How to Run

Make sure Python is installed on your computer.

Run the program with:

```text
V1
python "Mini Library_V1.py"
V2
python "Mini Library_V2.py"
```
